# Traffic Flow Optimization in a City Grid Using Dijkstra and A*

## Project Description
This project models a city as a weighted grid where intersections are nodes and roads represent connections with travel-time costs.

The goal is to find the optimal route between a starting point and a destination using two pathfinding algorithms: Dijkstra and A*.

## Algorithms
- Dijkstra's Algorithm
- A* Search Algorithm

## Traffic Simulation
Traffic congestion is simulated by increasing the weights of selected roads. The project compares routes and travel times before and after traffic congestion.

## Performance Evaluation
The algorithms are compared based on:
- Optimal travel cost
- Number of expanded nodes
- Runtime performance

## Technologies Used
- Python
- Kaggle Notebook
- Matplotlib
- Heap-based Priority Queue

## Conclusion
The project demonstrates how Dijkstra and A* can find optimal routes in a weighted city grid and how traffic congestion can affect route selection and travel time.
